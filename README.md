## Objective
Implement a basic TCP echo server and client in Python.
Demonstrate socket-level communication and submit a reflective report.

## Your Tasks

### Task 1 — Server (server.py)
Implement a TCP echo server in Python (10–20 lines).
The server must: bind to a port, listen for a connection,
receive a message, and echo it back to the client.
Place your file in: lab0/server.py

### Task 2 — Client (client.py)
Implement a TCP client (10–20 lines).
The client must: connect to the server, send a message,
receive the echo, and print it.
Place your file in: lab0/client.py
